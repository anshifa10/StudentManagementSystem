# Student Management System Using Java Swing

## 1. Project Overview

The Student Management System is a desktop application developed using Java Swing. It helps users manage student details through a graphical user interface.

## 2. Objectives

* Add new student records.
* Search for students using their ID.
* Update existing student details.
* Delete student records.
* Calculate grades based on marks.
* Save and load student records using file handling.

## 3. Technologies Used

* Programming Language: Java
* GUI: Java Swing
* IDE: IntelliJ IDEA
* Data Structure: ArrayList
* Storage: Text file
* Version Control: Git and GitHub

## 4. Features

* User-friendly graphical interface.
* Student ID, name, course and marks management.
* Automatic grade calculation.
* Input validation and error messages.
* File-based data persistence.

## 5. Java Concepts Used

* Classes and objects
* Encapsulation
* Constructors and methods
* ArrayList
* Conditional statements and loops
* Exception handling
* File handling
* Event handling with Java Swing

## 6. Project Structure

* `Main.java` — Starts the application.
* `Student.java` — Stores student details and calculates grades.
* `StudentManager.java` — Adds, searches, updates and deletes records.
* `StudentManagementGUI.java` — Provides the graphical interface.
* `FileHandler.java` — Saves and loads student records.

## 7. How to Run

1. Open the project in IntelliJ IDEA.
2. Ensure a compatible JDK is configured.
3. Run `Main.java`.
4. Use the GUI to manage student records.

## 8. Data Storage

Student records are stored in `students.txt`. The file is used to load existing records when the application starts and save changes made through the interface.
